# News ingestion, search, and freshness

## Current local configuration

The backend combines categorized RSS/Atom feeds with server-side GNews and NewsAPI adapters. Spring Boot does not load dotenv files by default; the local profile imports the root `.env`, and `scripts/Start-Backend.ps1` exports it. The local RSS list configures NASA (Science), SEC (Business), NIST (Technology and Health), CISA (Technology), PBS NewsHour (Politics), ESPN (Sports), and TechCrunch (Technology); all eight configured feeds returned HTTP 200 in the latest run. Both API keys are present in `.env`. A live NewsAPI top-headlines request returned HTTP 200. GNews returned HTTP 403; its documentation describes 403 as exhausted quota or an expired subscription, so the response does not establish that the key itself is invalid. The local refresh interval is six hours, retention is seven days, and the cache cap is 2,000 articles.

Set `NEWS_RSS_FEEDS` to approved, comma-separated URLs. Prefix a feed with a known category slug and `|` when the publisher's taxonomy should map explicitly. A recognized category in an RSS item takes priority; the configured category is used only when the item has no supported category. Feed entries retain their source title and excerpt (up to the database's 2,000-character description limit), article URL, author, publication time, source, and available category metadata. Unsupported categories remain uncategorized rather than being forced into a generic section. Review publisher terms before adding a feed. The BBC is deliberately not configured because its terms prohibit extracting metadata from RSS without a suitable licence.

The configured feed URLs are `https://www.nasa.gov/feed/`, `https://www.sec.gov/news/pressreleases.rss`, `https://www.nist.gov/news-events/news/rss.xml`, `https://www.nist.gov/news-events/health/rss.xml`, `https://www.cisa.gov/news.xml`, `https://www.pbs.org/newshour/feeds/rss/politics`, `https://www.espn.com/espn/rss/news`, and `https://techcrunch.com/feed/`. NASA, SEC, NIST, and CISA publish the linked feeds on their official domains. ESPN requires source attribution, links to the publisher article, no ads, and unchanged feed content; TechCrunch requires feed attribution and the full article link, prohibits ads and content changes, and its site terms limit use to personal noncommercial purposes. PBS RSS use is configured for this local personal, noncommercial development environment. Do not use these feeds in a public or commercial deployment without checking current source terms and obtaining any required permission. Feed availability does not itself grant image reuse rights. Article images remain optional and publisher supplied; no image binary is copied.

GNews uses `GNEWS_API_KEY` in the `X-Api-Key` header and the comma-separated `GNEWS_CATEGORIES` list: world, nation, business, technology, entertainment, sports, science, and health. Nation maps to World because the provider has no Politics category; general remains uncategorized. Eight categories every six hours mean 32 requests per day before manual runs. The official Free plan lists 100 requests/day, up to 10 articles per request, and a 12-hour delay; Free-plan use is limited to noncommercial purposes. The adapter paces category requests, applies a host cooldown after quota errors, and records partial failures. The live request returned HTTP 403. GNews documents 403 as quota exhaustion or subscription expiry, while 401 indicates an invalid key; check the account plan/quota before enabling this provider. See [GNews plan limits](https://docs.gnews.io/), [authentication](https://docs.gnews.io/authentication), [error handling](https://docs.gnews.io/error-handling), and [terms](https://gnews.io/legal/terms-of-service).

NewsAPI.org uses `NEWS_API_KEY` and defaults to its official `/v2/top-headlines` endpoint if `NEWS_API_BASE_URL` is blank. Set `NEWS_API_CATEGORIES` to supported values: business, entertainment, general, health, science, sports, or technology. The adapter supplies the configured country (default `us`), applies each selected category, requests up to 100 results, places the key in the documented `X-Api-Key` header, and tags articles with the configured category. The live key returned HTTP 200 for a business headline with an image. Politics and World are not available in this endpoint's category list. Keep the key in the ignored local `.env`; do not put it in a checked-in URL or frontend variable. The [authentication docs](https://newsapi.org/docs/authentication) describe the header method and the [top-headlines endpoint](https://newsapi.org/docs/endpoints/top-headlines) documents categories and image fields. NewsAPI's [Developer plan](https://newsapi.org/pricing) is limited to development and testing; check the account's plan before production use.

GNews does not offer Politics as a top-headlines category, and NewsAPI's top-headlines category list does not include Politics or World. PBS supplies Politics in this local configuration. No category is filled using unrelated stories. Avoid adding feeds with terms that disallow this kind of ingestion or display. A public feed URL alone does not establish permission to copy its metadata, images, or excerpts.

## Pipeline and stored fields

Provider entries pass through normalization, category mapping, canonical URL deduplication, and a transactional source/article insert. A unique canonical URL constraint and a pre-insert check make repeated runs idempotent. When a duplicate has no image and a later feed version supplies a valid HTTP(S) image URL, the pipeline fills only that missing image field; it never overwrites an existing image or other article metadata. Feed and run reports count image backfills separately from new article inserts and duplicate skips. Feeds and API providers are fetched server-side. The API reports publisher, category, image, excerpt, and timestamp metadata; it does not download publisher article pages or store full article text.

RSS parsing handles Atom links, RSS media thumbnails/content, image enclosures, image enclosures in Atom links, nested Media RSS groups, and image references included in publisher-supplied feed excerpts. It rejects unsafe image schemes and non-image media, resolves relative image URLs against the original article URL, and stores only safe HTTP(S) URLs. Provider images are used when supplied. The frontend preserves aspect ratio, gives images descriptive alt text, shows a loading background, and switches to a neutral publisher fallback when no usable image exists or a request fails. No Open Graph fetch or publisher-page scraping is performed; add that only if the source explicitly permits it. Images remain external and are not cached or copied.

Titles and article URLs are required. Publication timestamps must parse and fall within the retention window (default 48 hours) with no more than five minutes of future skew. Descriptions are reduced to plain text and retained up to the database column limit of 2,000 characters. Canonicalization strips common tracking parameters, fragments, default ports, and trailing slashes; credential-bearing URLs and non-HTTP(S) URLs are rejected. The local `.env` retains articles for 168 hours with a 2,000-article cap; cleanup can remove stories earlier at the count cap.

Provider HTTP uses a five-second connect timeout, twelve-second request timeout, fifteen-second total deadline, no redirects, and a five-MiB streaming body limit. Non-2xx responses are failures. HTTP 429/503 responses trigger a bounded cooldown honoring `Retry-After` when available; there are no immediate retries. Runs are serialized within one JVM. Cross-instance ingestion locking and durable quota accounting remain future work.

`GET /api/v1/news/status` reports actual last attempt/success, fetched/inserted/duplicate/invalid/failure counts, image backfills, configured provider names, scheduler delay, cache bounds, category/publisher counts, image count, and the last run's per-feed URL identifier, HTTP status, parsed/accepted/duplicate/rejected/saved counts, image candidates/backfills, category distribution, and last successful fetch. The endpoint strips query strings and credentials from displayed feed identifiers. A successful provider fetch means requests completed without reported failures; it does not imply that new rows were saved. The UI reports request success and fetched/inserted counts separately. `POST /api/v1/admin/ingestion/run` remains restricted to administrators; no public refresh trigger is exposed.

## Search and filters

`GET /api/v1/articles` supports category slug/name, source UUID, date range, pagination, and a `q` search. Search is case-insensitive across article title/description, publisher name/domain, and category name/slug. Category and source constraints combine with AND and are case-insensitive by slug/name; newest publication time is first. This makes a publisher-only query such as `NASA` find records whose headline does not mention NASA. The source directory returns stable source IDs; the Discover UI passes those IDs unchanged.

The FastAPI service exposes `/v1/embeddings` using `sentence-transformers/all-MiniLM-L6-v2`; it returns normalized 384-dimensional vectors. The backend uses the same model for article and query vectors, backfills existing articles in small scheduled batches, and ranks results with pgvector cosine similarity when storage is available. Flyway V6 conditionally prepares the embedding table and HNSW index, while `PostgresVectorSchema` can create them after pgvector is installed. This local PostgreSQL 18 installation does not have the `vector` extension files: no embedding table exists and the current article embedding count is zero. `/api/v1/search/semantic` therefore reports `mode=keyword-fallback` and `reason=pgvector-unavailable`; it does not claim semantic ranking. The real AI endpoint returned HTTP 200 with 384 dimensions and unit norm.
